# Grupo Imperio S.A | Transportes Imperio - Sitio Web Oficial

> Plataforma web corporativa y cotizador multimodal para Grupo Imperio S.A, líder en logística pesada, transporte regional y servicios portuarios en Centroamérica y Panamá.

---

## 🚀 Características del Sitio

- **Diseño Ultra Premium**: Interfaz moderna, minimalista con tipografía suiza, microinteracciones y animaciones sutiles.
- **Modo Claro / Modo Oscuro**: Soporte nativo con persistencia y adaptación de logotipo.
- **Cotizador Interactivo de Fletes**: Cálculo de rutas, tonelaje y conexión directa a WhatsApp y correo.
- **Showcase Interactivo de Flotilla**: Fichas técnicas dinámicas para Lowboy, Trailetas, Furgones Secos/Refrigerados, Vagonetas, Carretas y Graneleras.
- **Cálculo Dinámico de Trayectoria**: Contador automático de años de experiencia desde su fundación en el 2000.
- **100% Responsive**: Optimizado para dispositivos móviles, tablets y pantallas de escritorio 4K.

## 🛠️ Tecnologías

- HTML5 Semántico
- CSS3 Moderno (Custom Properties, Flexbox, CSS Grid)
- JavaScript Vanilla (ES6+)
- Despliegue en Vercel / GitHub Pages
